# Nexus

Nexus es el nombre del sistema interno nuevo que se está usando para procesar los reintegros. No
es algo que el cliente vea ni le importe — es "motor" de atrás, pero vale la pena entenderlo
porque explica un problema real que existía antes.

## El problema que resolvió

Antes, un cliente **Capitado** (el que llega por un convenio, como OSDE, sin pagar directo) no
podía pedir reintegros tan fácil como uno que paga con tarjeta. La razón: el sistema viejo solo
reconocía bien a los clientes que habían pasado por una compra directa — como el cliente Capitado
nunca "compra" en ese sentido, el sistema no tenía registrado su historial y el reintegro se
trababa.

Nexus se construyó justamente para conectar también a los clientes Capitado con el circuito de
reintegros, algo que antes simplemente no funcionaba bien para ellos.

## Cómo convive con el sistema anterior

El pasaje no fue de un día para el otro — durante un tiempo, una parte de los reintegros todavía
se procesa con el sistema viejo mientras la otra parte ya usa Nexus, hasta que la migración
termine del todo.
