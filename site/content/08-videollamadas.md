# Videollamadas

Una de las formas más usadas de Vetify: el cliente agenda una consulta por video con un
veterinario, sin salir de su casa. Sirve para dudas rápidas, seguimiento de un tratamiento, o para
decidir si hace falta ir presencial o no.

## Cómo se usa

- El cliente elige el motivo de la consulta, adjunta fotos o videos si hace falta, y elige día y
  horario.
- Puede cancelar o reprogramar con anticipación.
- Si tiene más de una mascota, elige para cuál es la consulta.

## Una excepción a tener en cuenta

La mayoría de los planes tienen videollamadas **sin límite**. Pero algunos planes puntuales de
Capitado tienen un **límite de videollamadas por año** para cada mascota — pensado para que el
beneficio siga siendo sostenible en ese tipo de convenio. Si el cliente llega a ese límite, la app
le avisa claramente y le explica cuándo se renueva.
