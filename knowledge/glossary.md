# Glosario

> Términos del dominio del proyecto, para que todo el squad hable el mismo idioma. Sembrado desde
> `automation/qa-workspace/`.

| Término | Significado |
|---|---|
| Capitado | El usuario NO compra el plan directo — lo adquiere vía otra prestación que ya tiene (ej. OSDE, un banco). Modelo corporativo con el beneficio ya integrado. |
| Adquiriente | El usuario compra el plan directo (checkout con tarjeta). |
| HU | Historia de Usuario — tarjeta de Jira que aporta valor directo al usuario. |
| DoD | Definition of Done — criterios para que una HU se considere "lista" del lado de desarrollo/QA. Ver `automation/core/dod/dod-core.md`. |
| DoR | Definition of Ready — criterios para que una HU se considere lista para pasar a desarrollo (Fase 3 de este proyecto, todavía no construida). |
| CDS | Centro de Servicios — atención telefónica al tutor; también coordina hoy el agendamiento presencial. |
| Filecase | Identificador de expediente en Nexus (ej. `"3147-1"`) — equivalente al `clExpediente` de SISE. |
| SISE | Sistema de gestión legado con el que Reintegros integra hoy — en migración hacia Nexus. |
| Nexus | Plataforma interna nueva ("Quantum") hacia la que se está migrando Reintegros. |
| Token de validación | Código alfanumérico corto, generado en la webapp del tutor y validado por el prestador, para confirmar cobertura en atención presencial sin cobrar la consulta. |
